## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/SketchQuecto.git`
2. `cd SketchQuecto`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure SketchQuecto, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
